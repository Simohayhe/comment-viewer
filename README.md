# コメビュー (Comment Viewer)

Twitch とツイキャスのコメント・ビッツ・サブスク・アイテムを、ひとつの画面にまとめて表示する Windows アプリです。
ゲーム中は画面のすみに小さく通知を出し、ずんだもんの声でコメントを読み上げることもできます。

> このリポジトリは配布用です。ソースコードは置いていません。

## ダウンロード

[Releases](../../releases/latest) から `CommentViewer-Setup-<版>.exe` を落として実行してください。

- 対応: Windows 10 / 11(64bit)
- 管理者の権限は要りません(自分のユーザーの場所に入ります)
- 新しい版が出ると、アプリの上のバーに 🔔 が出て、押すだけで更新できます

## できること

- **コメントをまとめて表示**: Twitch・ツイキャスのコメント、ビッツ、サブスク(ギフト・継続)、レイド、フォロー、チャンネルポイント、ツイキャスのアイテム(お茶・お茶爆など)
- **初見・久しぶりが分かる**: 初めての人には「初見」、しばらくぶりの人には「n日ぶり」の印が付きます
- **URL を貼るだけで読める**: ログインしなくても、配信ページの URL だけでコメントを読めます(自分以外の配信も可)
- **ゲーム中の通知**: コメビューが裏にあるときにコメントが来ると、画面のすみに小さく通知を出します。クリックはゲームにそのまま届き、ゲームの操作も奪いません
- **読み上げ**: Windows の声か、VOICEVOX(ずんだもん・四国めたん など)の声で読み上げます。音量・速さを調整できます
- **常に手前に表示**: コメビューの画面をほかのウィンドウより前に出したままにできます
- **Twitch のエモート**: コメントのエモートを画像で表示します
- **アラート**: フォロー・サブスクなどを配信画面に大きく演出します(OBS)
- **スタンプ**: コメントに決めた言葉が入っていたら、好きな画像・GIF に置き換えて表示します(ねこ・ハートなど最初から入っています)

## 使い方

### 1. コメントを読む

「設定」→「つなぐ」で、次のどちらかを使います。

| 方法 | 取れるもの | 手順 |
|---|---|---|
| **ログインする**(自分の配信向け) | すべて | 「Twitch でログイン」→ 画面に出たコードを https://www.twitch.tv/activate で入力 /「ツイキャスでログイン」→ いつものブラウザが開くので、そこで許可 |
| **URL を貼る**(ログイン不要) | Twitch: フォロー・チャンネルポイント以外 / ツイキャス: コメントのみ | 配信ページの URL(`https://www.twitch.tv/〇〇` など)を貼って「読む」 |

ログイン前に見た目や通知を確かめたいときは、「表示」の **テストモード** をオンにすると、お試しのコメントが流れます。

### 2. ゲーム中の通知

「設定」→「通知」の **画面の右上に通知する** をオンにします(初めはオフです)。

- 出す場所: 右上・右下・左上・左下・上の真ん中から選べます。「自分で決める」で見本のカードをドラッグして好きな場所にもできます
- 表示する時間・同時に出す数も変えられます
- 「試す」で、5秒後に通知を1件出します

ゲームを **排他フルスクリーン** にしていると、通知が上に出ないことがあります。そのときは **ボーダーレス(ウィンドウ化フルスクリーン)** にするか、下の読み上げを使ってください。

### 3. 読み上げ

「設定」→「音・読み上げ」で、**音** を「コメントを読み上げ」にします。

- 声: 「Windows の声」か「VOICEVOX(ずんだもんなど)」
- VOICEVOX を選んだら「同意して準備」を押します。声のデータ(約170MB)を自動で用意します。VOICEVOX のアプリは要りません
- 鳴らすとき(通知のときだけ / コメントが来るたびに)、音量、速さ、名前も読むか、長いコメントをどこで切るかを選べます

**VOICEVOX の声を配信で使うときは、配信の説明欄などに「VOICEVOX:ずんだもん」のようなクレジット表記が必要です**([VOICEVOX 利用規約](https://voicevox.hiroshiba.jp/term/))。

### 4. 記録を消す

「設定」→「記録」の **来訪の記録を消す** で、「初見」「n日ぶり」の判定に使う記録とコメントの記録を全部消せます(2回確認してから消します)。

## データの置き場所

`%LOCALAPPDATA%\CommentViewer` に保存します。

- 設定・来訪の記録・ログイン情報・VOICEVOX の声のデータ
- **ログイン情報は Windows の暗号化(DPAPI)で保存**し、そのPC・そのユーザーでしか読めません
- コメントやログイン情報を外部のサーバーへ送ることはありません(Twitch・ツイキャスと通信するだけです)
- アンインストールしてもデータは残ります。完全に消したいときは上のフォルダを削除してください

## OBS で使う

「設定」→「OBS で使う」で、文字の大きさ・件数・消えるまでの時間・配色などを選んで「コピー」を押し、OBS の「ソース」→「ブラウザ」の URL に貼ります。配信画面にコメントを重ねられます(コメビューを起動している間、OBS と同じ PC で使えます)。

## アラート(OBS)

フォロー・サブスク・ギフトサブスク・ビッツ・レイド・チャンネルポイント・ツイキャスのアイテム(お茶・お茶爆など)が来たとき、配信画面の真ん中に大きく演出を出せます。

- 「設定」→「アラート(OBS)」の URL を、OBS の「ブラウザ」ソースに入れます(画面全体の大きさ、例: 1920×1080)
- 種類ごとに、オン/オフ・**スタンプ**(登録した画像から選ぶ)・色・文言・効果音を決められます。行をクリックすると開きます
- 文言には `{名前}` `{数}` `{内容}` を使えます
- 設定画面のプレビューで見え方を確かめられ、変えた設定は OBS にもすぐ反映されます
